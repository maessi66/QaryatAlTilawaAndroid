# تطبيق قرية التلاوة – نجع المهيدات

مشروع Android WebView يضم موقع قرية التلاوة داخل التطبيق، مع دعم JavaScript وFirebase ورفع صورة المتسابق وفتح الروابط الخارجية.

## البناء

يتم البناء تلقائياً بواسطة GitHub Actions من خلال الملف `.github/workflows/build-apk.yml`، وينتج ملف APK تجريبي (Debug APK).
